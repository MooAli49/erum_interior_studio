# ERUM Knowledge & Content Hub

## Purpose

Content is a core part of the product, not an optional blog.

The long-term platform should combine:

-   ERUM Portfolio
-   Knowledge Library
-   Video Library
-   Engineer Personal Brand
-   Lead Generation

## Content Types

### Article

Fields:

-   Title
-   Cover Image
-   Content
-   Images
-   Category
-   Tags
-   Related Projects
-   Related Services
-   Related Videos
-   SEO Title
-   Meta Description
-   Publication Date

### Video

Fields:

-   Title
-   Video Source
-   Thumbnail
-   Description
-   Transcript when useful
-   Category
-   Tags
-   Related Projects

-   Related Articles
-   SEO Title

## Video Requirements

Support:

-   Landscape videos
-   Vertical videos
-   YouTube / Vimeo embedding
-   Direct hosting when justified
-   Future source changes without redesign

The implementation should prioritize quality, loading speed, and hosting
cost.

## Video Library

Users should eventually be able to:

-   Search
-   Filter by category
-   Filter by topic
-   Browse latest
-   Browse popular
-   Navigate related content

Pagination or infinite scroll can be selected during UX design.

## Content Repurposing

One piece of content should be reusable in multiple contexts.

Example:

``` text
Video: How to Choose the Right Rug Size
       ↓
Video Library
       ↓
Related Article
       ↓
Interior Design Service
       ↓
Related Project
       ↓
Start Your Project
```
