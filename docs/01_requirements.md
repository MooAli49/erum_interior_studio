# ERUM Website --- Requirements

## 1. Main Objectives

The website should:

1.  Present ERUM projects professionally.
2.  Build trust and authority.
3.  Differentiate ERUM from ordinary finishing contractors.
4.  Explain the working process clearly.
5.  Convert visitors into qualified leads.
6.  Support traffic from Facebook, Instagram, TikTok, Google, and other
    channels.
7.  Be technically prepared for SEO.
8.  Allow content and projects to be updated without developer
    involvement.

## 2. Target Experience

The website should feel:

-   Premium
-   Architectural
-   Modern
-   Clean
-   Sophisticated
-   Visual-first
-   Fast
-   Mobile-first

Real ERUM project photography should be preferred over stock imagery.

-   Arabic
