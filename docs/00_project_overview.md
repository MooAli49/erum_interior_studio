# ERUM Interior Studio --- Website Project

## Project Goal

Build the official digital presence for **ERUM Interior Studio** as a
premium interior design, execution, and project management brand.

The website is not intended to be a simple company profile. It should
function as:

-   Premium Portfolio
-   Brand Authority Platform
-   Knowledge & Video Library
-   Lead Generation Platform
-   Personal Brand platform for Engineer Abdelrahman
-   SEO-ready long-term content platform

## Core Positioning

> Interior Design Studio + Execution Company + Project Management System

The portfolio and real project work are the primary visual focus.

## Core Business Journey

Visitor → Interested → Qualified Lead → Consultation → Client

## Primary CTA

-   Start Your Project
-   Discuss Your Project

## Current Visual Direction

Based on the currently available social media assets:

-   Premium
-   Modern
-   Architectural
-   Minimal
-   Sophisticated
-   Navy / Deep Blue
-   Gold / Orange Gold
-   White

**Note:** The visual direction is preliminary and must be validated
against the client's brand assets and preferences before final UI
design.
